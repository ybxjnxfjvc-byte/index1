# Local security lab

This folder demonstrates server-side controls without changing the public GitHub Pages trainer.

Implemented controls:
- localhost-only binding;
- bearer token from environment;
- constant-time token comparison;
- 4096-byte body limit;
- JSON allow-list validation;
- generic client errors;
- metadata-only logs;
- parameterized SQLite operations.

Run instructions are in `../docs/local-ops.md`.
